ProofHire AI

A FastAPI app with a dark dashboard that compares one resume claim with bounded GitHub code evidence and returns review questions and answer feedback.

One audit, from request to result

The deterministic path works without keys. Optional Gemini/OpenAI analysis is accepted only when its citations match fetched files and line ranges; otherwise the backend falls back to deterministic results.

Reference route through the code

This is a reference route; it was prepared from the source and was not a live editor tour.

  1. static/index.html: the page polls service health, loads sample payloads, renders the audit in renderReport, and submits viva answers with vanilla JavaScript.
  2. main.py — dashboard, audit: serves the page and coordinates input, keys, bundled samples, and repository retrieval.
  3. main.py — repository_key, fetch_repository: validates GitHub URLs, retrieves a bounded tree and files, numbers evidence, and uses the TTL cache.
  4. main.py — build_heuristic_audit, build_llm_audit, evaluate_viva: creates structured evidence/questions, validates model citations, and grades an answer.

To change this, start here

  • Change or add an offline demo: edit SAMPLE_DATA near the top of main.py.
  • Teach the fallback analyzer another technology: add patterns to FEATURES and a small example to FEATURE_FIX_SNIPPETS.
  • Adjust file selection, byte/line caps, or cache lifetime: start with MAX_SOURCE_FILES, MAX_FILE_BYTES, MAX_FILE_LINES, REPO_CACHE_TTL_SECONDS, and fetch_repository.
  • Adjust the dashboard layout: edit static/index.html; the UI calls same-origin API routes.

A practice to reuse

Make important claims testable: this backend treats a source citation as valid only when the path and 1-based line range exist in the fetched file map (citation_is_valid). The approved acceptance criteria in prd.md > Audit Request became checks for real line ranges and sample responses. On another project, turn a statement such as “the result includes evidence” into a concrete check of where that evidence came from.

Run it again

python -m pip install -r requirements.txt
python -m uvicorn main:app --reload

Open http://127.0.0.1:8000/ for the dashboard or /docs for the API explorer. Tailwind and Lucide assets load from public CDNs. No key is required for sample audits. Copy .env.example to local .env only for optional provider testing; never commit secrets.
